How a call is scored

Six skills, built from the call analysis.

After each call ElevenLabs marks evaluation criteria pass or fail and fills in data collection fields. A skill is the share of its data points that passed. Older agent versions tracked fewer criteria, so some calls are scored on fewer points.

Also collected on every call: score_0_100 call_outcome one_thing_done_well top_improvement_area persona_played difficulty objection_count situation / problem / implication / needpayoff obj_listened / acknowledged / explored / responded_with_value rep_talk_ratio_high scenario_identified
